## Selected work

### [Shamash](https://github.com/aalsanie/shamash)

JVM architecture enforcement for Java and Kotlin codebases.

Analyzes source code and compiled bytecode to detect architectural violations, dependency cycles, coupling problems, API restrictions, and architectural drift.

Available through CLI, GitHub Actions, and IntelliJ.

### [Codes](https://github.com/aalsanie/codes)

A JVM library for stable application outcome identities and explicit protocol-boundary mappings.

Keeps domain outcomes independent from HTTP, gRPC, serialization, and framework-specific representations.

Published on Maven Central.

### [Enkidu](https://github.com/aalsanie/enkidu)

A JVM linkage analyzer that detects runtime dependency problems before deployment.

It analyzes compiled bytecode against the runtime classpath to identify missing symbols, binary incompatibilities, access problems, classpath shadowing, duplicate classes, and ServiceLoader issues.
